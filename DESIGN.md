# JNavigator — Design System (DESIGN.md)
Theme: Obsidian / GitHub & VS Code Dark Modern
Target: Oracle EBS Enterprise Developer & DBA Studio

## 1. Color Palette (Dark Theme)
- Background Dark: #0d1117 (Main app canvas)
- Background Deeper: #010409 (Deep background / sub-panels)
- Background Surface: #161b22 (Sidebars, cards, active panels)
- Background Elevated: #21262d (Headers, active tabs, modals)
- Background Hover: #262c36 (Subtle hover state)

## 2. Borders & Dividers
- Border: #30363d (Crisp 1px border)
- Border Light: #3c444d (Hover border)
- No glowing drop shadows or fuzzy blur overlays

## 3. Typography
- UI Font Stack: system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif (zero network latency, native OS feel)
- Code Font: 'JetBrains Mono', 'Fira Code', Consolas, monospace
- Text Main: #e6edf3 (High legibility, neutral gray-white, no purple tint)
- Text Bright: #ffffff
- Text Muted: #8b949e
- Text Dim: #6e7681

## 4. Accent & Signal Palette
- Primary Accent: #1f6feb (Enterprise Developer Blue)
- Secondary Accent: #58a6ff (Sky Blue)
- Success: #3fb950 / Background #238636
- Danger: #f85149 / Background #da3633
- Warning: #d29922
- Cyan/Info: #38bdf8

## 5. Reduction of AI Slop & Anti-Patterns
- Removed AI-slop fonts (Outfit, Inter) in favor of crisp native system font stack.
- Removed floating glows, drop-shadow neon halos, and pastel gradient texts.
- Removed emoji clutter on primary navigation tabs and core action buttons.
- Renamed and redesigned Antigravity AI Chat into a clean, understated AI Assistant.
- Cleaned up prompt chips and chat bubbles to look like terminal / code assistant output rather than a toy chatbot.
- Remodeled Monaco Editor theme jnav-dark to match VS Code / GitHub Dark Modern code highlights.
